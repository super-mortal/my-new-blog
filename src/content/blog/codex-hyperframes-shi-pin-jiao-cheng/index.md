# 用 Codex 做视频：HyperFrames 新手入门教程

> 很多朋友问我，Codex 除了写代码还能干嘛？我最近发现一个好玩的玩法：用 Codex + HyperFrames 插件做视频。不用装 AE，不用学剪辑，只要会打字，就能把一句话变成一段动画视频。这篇是给完全没接触过的人写的，照着做就能出片

## 一.需要准备什么

1. 电脑装好 Codex 桌面版
2. 电脑能联网
3. 会打字（认真的）

不需要会 HTML，不需要会 AE，不需要懂剪辑，这些 Codex 都会帮你搞定。

## 二.认识 HyperFrames 插件

HyperFrames 是 Codex 里做视频的插件，原理是用 HTML + GSAP 写动画，最后渲染成 MP4。它比较擅长做：

产品演示动画；  
标题卡、片头片尾；  
流程介绍视频；  
字幕、歌词、语音配套动画；  
发朋友圈和短视频平台的内容。

> 小提示：在 Codex 对话里输入 @hyperframes，就能直接调用这个插件

## 三.照着这个模板说需求

把下面的模板复制给 Codex：

> 我想做一个[类型]视频，主题是[内容]，时长[多少秒]，风格[什么风格]，画面分成[几幕]，每幕讲[内容点]，最后输出 MP4

举个例子：

> 我想做一个产品演示视频，主题是“三步生成 AI 视频”，时长 15 秒，苹果极简风格，先讲标题，再依次讲角色生成、场景生成、视频生成，最后总结

> 经验：需求说得越清楚，Codex 做出来越接近你想要的效果。风格、时长、每幕讲什么，这三样最好先想好

## 四.Codex 会帮你做什么

拿到需求后，Codex 会自动完成这些事：

1. 帮你拆演示意图，把文案和分镜排好
2. 用 HyperFrames 初始化项目
3. 用 HTML + GSAP 写动画
4. 自动检查排版、文字对比度、动画冲突
5. 修完问题后渲染成 MP4

## 五.想改内容怎么办

直接说人话就行，比如：

把“角色生成”改成“剧本生成”；  
颜色太蓝了，改成绿色；  
时长改成 20 秒；  
标题换成“三步搞定”。

Codex 会听懂你的修改，改好之后重新渲染。不用自己找代码在哪里。

## 六.渲染成 MP4

最后 Codex 会把视频渲染成 MP4 文件，双击就能播放。渲染需要 FFmpeg，如果电脑没装，Codex 会帮你自动安装并配置环境变量。

底层渲染命令大概长这样，知道一下就行，不用自己敲：

```bash
npx hyperframes render --output my-video.mp4 --quality standard --fps 30
```

## 常见疑问

**Q1：index.html 打开是空白的？**

A：index.html 是源文件，不是成品。真正的成品是渲染出来的 MP4，打开 MP4 就行

**Q2：必须要会 HTML 吗？**

A：不用。代码、检查、修 bug、渲染都由 Codex 完成，你只需要说需求、看效果、提修改

**Q3：能做多长的视频？**

A：几秒到几分钟都可以。新手建议先从 10-20 秒的短片开始，内容少，改起来快

**Q4：渲染会很慢吗？**

A：15 秒的 1080p 视频一般几十秒就能渲染完，具体看电脑性能

## 总结

用 Codex 做视频其实就一句话：说需求，看效果，提修改。

新手只要记住四步：

在对话里输入 @hyperframes；  
把需求模板说清楚；  
等 Codex 生成动画并检查；  
渲染成 MP4 拿成品。

剩下的事情，交给 Codex 就行。
